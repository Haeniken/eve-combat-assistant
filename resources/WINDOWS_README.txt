EVE COMBAT ASSISTANT — Windows x64

Помощник для соло-PvP: предполагаемые сборки выбранного противника,
дистанция боя, урон, заряды, скорость, нейтрализаторы и резисты.
Оценка основана на публичных потерях zKillboard. Текущий фит противника
может отличаться от выбранного примера.

ЗАПУСК И ПЕРВАЯ НАСТРОЙКА

Windows 10/11 x64, OpenGL 3.3 и компонент Windows OCR для выбранного языка.
Используйте оконный режим EVE или окно без рамок. Python и Rust не нужны.
Запуск: eve-combat-assistant.exe или Запустить.cmd.
Демонстрация.cmd показывает пример без сети с отдельными настройками.

Новую версию можно установить поверх старой: настройки, вход персонажа
и пользовательская база сохраняются.

Откройте шестерёнку:
1. Мой корабль: вставьте полный EFT из EVE/Pyfa с зарядами и трюмом.
2. EVE SSO: войдите персонажем для загрузки навыков и имплантов.
   Пароль вводится на сайте EVE. Фит из ESI может быть неполным;
   при необходимости используйте ручной EFT.
3. Экран: выделите ник и расстояние в правой панели Selected Item,
   затем ники и корпуса на карточках захваченных целей без колец.
   Звёздочка необязательна. Нажмите «Проверить сейчас», проверьте
   «Результат проверки», включите распознавание и сохраните настройки.
4. Вид: настройте масштаб и прозрачность. При пропуске кликов настройки
   открываются через системный трей. Цель можно задать вручную в «Цель».

БАЗА И СБОРКИ

Готовая база всех 423 корпусов уже включена: 90 полных дней,
30.07–27.10.2026. Для редкого корпуса подходящих потерь может не быть.
«Данные → Обновить базу всех кораблей» актуализирует весь каталог.
Прогресс показывает проверенные дни, загрузку и новые записи.
Обновление можно остановить и продолжить. Выполняйте его перед игрой.

Популярные сборки читаются локально. Фит выбранного пилота ищется
отдельно и добавляется сверху, если есть подходящая потеря на этом корпусе.
Проценты относятся к подходящим потерям после фильтров, а не ко всем
живым кораблям. Ошибка сети не скрывает локальные сборки.

Нажатие на сборку меняет расчёт, двойной щелчок открывает EFT,
правая кнопка — действия с вариантом. Жёлтые SCRAM/WEB/POINT/NEUT/NOS
возле корпуса относятся к выбранной сборке.

ПОКАЗАТЕЛИ

Линейка: белая метка — цель, бирюзовый диапазон — рекомендуемая дистанция,
янтарная метка — оценочная дальность оружия противника с дальними зарядами.
«Его урон» относится к выбранному примеру. «Твой заряд» выбирается из
вашего фита и трюма; вспомогательные скрипты как боеприпасы не предлагаются.
Нейтрики: количество × размер и дальность каждой группы.
Скорость: база и AB/MWD без перегрева. Его навыки V, ваши — загруженные.
Янтарный выделяет его преимущество, бирюзовый — ваше.
Резисты: итог сверху, база снизу. Тёмная полоса — база без модулей,
яркая — прибавка модулей. Рамка «ДЫРА» отмечает слабый резист.
Abyssal-модули заменяются стандартными аналогами с предупреждением
о неточной оценке.

SOLO-рейтинг: собственная шкала помощника 1000–8999 за всю историю
пилота на zKillboard. При недостатке данных — прочерк. «ГРУППА» и
«БЛОБ 10+» описывают историю убийств, а не текущий флот.
Сегменты кружка — цветовой уровень противника. Ваш SOLO-рейтинг виден
возле своего фита после входа через EVE SSO; шкала у обоих одинакова.
Точка внутри «ГРУППА»/«БЛОБ 10+»: зелёная — бой до 24 часов назад,
жёлтая — от 24 до 72 часов. При наведении на точку видно время участия.
Проверка выполняется в фоне, одна страница с часовым кешем; если
подтверждения нет, точка не показывается.
Формула и цвета: PILOT_RATING.md. Боевые расчёты: FIT_METRICS.md.

При SSO-входе текущий корабль проверяется раз в минуту. При пересадке
обновляется доступный фит; на том же корабле ручной EFT сохраняется.
После изменения модулей на месте импортируйте EFT заново.
«Экран → Хранить исчезнувшую цель»: по умолчанию 60 секунд.

ДИАГНОСТИКА И ДАННЫЕ

Системный отчёт debug/system.json создаётся при каждом запуске:
Windows, процессор, память, графика, экраны, OCR и версии библиотек.
Подробные журналы и снимки по умолчанию выключены.

Если цель не распознаётся, повторите проверку областей в «Экран».
Для разбора ошибки включите «Подробная диагностика», сохраните настройки
и воспроизведите проблему. «Открыть папку» ведёт в debug: журналы OCR,
снимки выбранных областей, расчёты фитов и трассировка HTTP-запросов.
Токены и полные HTTP-ответы не записываются. Перед публичной отправкой
проверьте снимки: на них видны игровые ники и интерфейс.

Настройки, обновления и кеш: %LOCALAPPDATA%\EVECombatAssistant.
Токены SSO в sso.dat защищены Windows DPAPI. «Выйти» удаляет локальный вход.
Стартовая база seed/seed.sqlite3 читается без изменений.
Для другой папки: --data-dir "C:\EVEData". Используйте локальный диск.

Удаление: Параметры Windows → Приложения → Установленные приложения.
Данные сохраняются, если не включить флажок их удаления.
Служб и задач планировщика нет.
