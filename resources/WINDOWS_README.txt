EVE COMBAT ASSISTANT — Windows x64

Помощник для соло-PvP в EVE Online. Показывает возможный фит противника,
дистанцию боя, урон, заряды, скорость, нейтрализаторы и резисты.
Источник фитов — публичные потери zKillboard. Установленный на встреченном
корабле фит может отличаться от примера.

ЗАПУСК

Нужны Windows 10/11 x64, OpenGL 3.3 и компонент Windows OCR для выбранного
языка. EVE должна работать в оконном режиме или окне без рамок.
Python и Rust для запуска не требуются.

Запустить.cmd открывает помощник. Демонстрация.cmd показывает пример
без сети с отдельными настройками. Portable-архив распаковывается целиком;
папки seed и licenses должны находиться рядом с EXE.

ПЕРВАЯ НАСТРОЙКА

Откройте шестерёнку.
1. Мой корабль: вставьте полный EFT из EVE или Pyfa с зарядами и трюмом.
2. EVE SSO: войдите персонажем для загрузки навыков и имплантов. Пароль
   вводится на сайте EVE Online. Доступный снимок фита из ESI можно
   импортировать; при неполных данных используйте ручной EFT.
3. Экран: выделите ник и расстояние в Selected Item, затем ники и корпуса
   на карточках захваченных целей без колец. Проверьте результат кнопкой
   «Проверить сейчас», включите распознавание и сохраните настройки.
4. Вид: настройте масштаб и прозрачность. При пропуске кликов настройки
   открываются через системный трей.

В разделе «Цель» корпус и ник можно выбрать вручную. Ввод в поле корпуса
ищет его в каталоге. Кнопка «Сохранить» применяет настройки.

ПОИСК ПИЛОТА

Лупа возле шестерёнки открывает поиск по нику. Введите ник и нажмите Enter.
Ctrl+V в главном окне сам раскрывает поиск и проверяет вставленный ник.

Показаны SOLO-рейтинг, групповой маркер и последняя PvP-потеря корабля.
Капсулы пропускаются. Клик по потере или «В помощник» выбирает её пилота,
корпус и точный фит для расчёта. EFT открывается отдельной ссылкой.
Дата потери отображается в часовом поясе системы.

Клик по рейтингу открывает профиль этого персонажа на zKillboard.
Свой рейтинг ведёт к персонажу, выбранному через EVE SSO.
Если статистика недоступна и сохранённой оценки нет, показан прочерк.

Esc в главном окне сбрасывает цель и поиск, включает OCR и запускает новое
чтение. Удержание исчезнувшей цели задаётся в «Экран», по умолчанию 60 секунд.
Вне активного окна EVE OCR приостановлен, если включена эта настройка.

БАЗА И ОЦЕНКИ

В комплекте — база всех 423 корпусов каталога за 90 полных дней,
30.07–27.10.2026. Записи есть у 369 корпусов; у остальных выборка пуста.
Популярные сборки читаются с диска, персональные данные загружаются отдельно.

«Данные → Обновить базу всех кораблей» проверяет весь каталог от свежих
дат к старым. Прогресс показывает дни, загрузку и число новых записей.
Обновление можно остановить и продолжить. Выполняйте его перед игрой.

Доли сборок считаются среди подходящих потерь. Резисты показывают базу
корпуса и итог выбранного фита; рамка отмечает дыру. Скорости сравниваются
без перегрева, противник считается с навыками V, свой корабль — с вашими.
Дальность оружия служит оценкой для кайта. Для дроновой сборки без пушек
и ракет показана дальность управления дронами. Для Abyssal используются
обычные аналоги с предупреждением о неточности.

ДИАГНОСТИКА И ДАННЫЕ

Данные находятся в %LOCALAPPDATA%\EVECombatAssistant.
При установке поверх настройки, вход EVE SSO и пользовательская база
сохраняются. Удаление данных при деинсталляции выбирается отдельно.

Системный отчёт debug/system.json записывается при запуске.
Подробные журналы и снимки по умолчанию выключены. Для разбора ошибки
включите «Экран → Подробная диагностика», сохраните настройки и повторите
действие. Кнопка «Открыть папку» ведёт к журналам и снимкам.

Для OCR и фитов хранятся по четыре текстовых файла до 20 МиБ каждый:
записи дописываются, самые старые части вытесняются автоматически.
Для снимков действует предел 512 PNG и 64 МиБ. Перед публичной отправкой
проверьте изображения: на них могут быть ники и игровой интерфейс.
