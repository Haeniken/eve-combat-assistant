EVE COMBAT ASSISTANT — Windows x64

Запуск: eve-combat-assistant.exe или Запустить.cmd.
Демонстрация.cmd запускает пример без настройки и без доступа к сети.
Python, Rust и WSL для запуска не нужны.

ПЕРВАЯ НАСТРОЙКА

1. Шестерёнка → Мой корабль: вставь экспорт фита из EVE/Pyfa или открой
   EFT/TXT. Включи заряды, дронов и боеприпасы в трюме. Укажи уровень
   навыков или импортируй JSON навыков ESI.
2. Цель: выбери корпус. Данные → Обновить общую статистику.
   Подготовь нужные корпуса до игры. Обновление общее для всех игроков
   и регионов zKillboard, выполняется только вручную.
3. Экран: выдели неподвижную панель Selected Item с ником и корпусом.
   Она обновляется при смене выбранного игрока. Включи чтение экрана.
   По умолчанию чтение приостанавливается вне активного окна EVE.
4. Вид: настрой прозрачность фона, прозрачность содержимого, ширину
   и масштаб 75–175%. Настройки доступны через шестерёнку и системный трей.

Рекомендуется оконный режим EVE или окно без рамок. Нужен Windows 10/11,
драйвер с OpenGL 3.3 и компонент Windows OCR для выбранного языка.

КАК ПОЛЬЗОВАТЬСЯ

Основные варианты показываются из локальной базы. Сведения выбранного
пилота загружаются отдельно; подходящий фит добавляется сверху.
Для персонального поиска должен быть виден ник. Можно ввести цель вручную.
Распознаются английские названия корпусов; ники могут содержать кириллицу.

Нажми на вариант фита: рекомендация дистанции, боеприпасов, урона,
нейтрализаторов, скорости и резистов относится к выбранному варианту.
Контекстное меню позволяет посмотреть EFT или исключить вариант.

Проценты считаются среди доступных подходящих потерь корпуса после
фильтрации флотовых записей. Флоты отсекаются эвристически по атакующим,
модулям и сериям потерь. Демонстрация использует только небольшую выборку
Rifter, она не является полной статистикой zKillboard.

Модель оценивает дистанцию и применение урона; активный ремонт,
капбустеры, перегрев и участие других кораблей полностью не моделируются.
Собственный фит нужно импортировать повторно после изменения в игре.
Чтение реальной панели EVE требует подбора области и проверки на своей игре.

ХРАНЕНИЕ

Настройки и база: %LOCALAPPDATA%\EVECombatAssistant
Демонстрация использует отдельную подпапку demo.
Для другой папки: --data-dir "C:\EVEData". Базу храни на локальном диске.

Лицензии компонентов и игровых данных: THIRD_PARTY_NOTICES.md и licenses/.

УДАЛЕНИЕ

Открой «Параметры Windows → Приложения → Установленные приложения»
и выбери EVE Combat Assistant. Деинсталлятор закроет приложение.
Настройки и база сохраняются, если не включить флажок их удаления.
Служб, задач планировщика и автозапуска приложение не создаёт.
