# Дальность, нейтрализаторы и скорость

Показатели относятся к выбранному примеру фита противника. Его навыки считаются V. Это оценка опубликованной сборки: установленное сейчас вооружение и заряды могут отличаться. Для Abyssal используются обычные аналоги, указанные в предупреждении.

## Дальность оружия

В карточке «ЕГО УРОН» отдельно показана дальность самого дальнобойного установленного боевого оружия. Дроны, истребители, нейтрализаторы, электронная борьба и вспомогательные скрипты в неё не входят. Состав урона выше по-прежнему относится к заряду выбранного примера, включая его дронов; дальний заряд может наносить другие типы урона.

Для каждого установленного оружия перебираются все опубликованные совместимые боевые заряды из каталога, с проверкой группы и размера. Наличие заряда в трюме примера не требуется. Каждый вариант пересчитывается dogma-движком с полным фитом: учитываются навыки V, бонусы корпуса, модули, риги, загруженные вспомогательные скрипты и штатные штрафы. Нельзя подставлять T2-заряд в орудие, которое его не принимает. Среди вариантов выбирается наибольшая дальность.

| Оружие | Показанный рубеж |
| --- | --- |
| Пушки с falloff | Optimal + 2 × falloff; помечается ≈ |
| Оружие без falloff, например disintegrator или Vorton | Модифицированный optimal |
| Ракеты | Верхняя оценка пути до неподвижной цели с разгоном и округлением времени полёта; помечается ≈ |
| Смартбомбы | Радиус действия установленного модуля |

У пушек с falloff нет конечной границы попаданий. На optimal + 2 × falloff шанс попадания при идеальном tracking составляет 6,25%, ожидаемый урон — около 6% номинального. Выбранная граница — удобное приближение для оценки кайта, а не гарантированно безопасная дистанция. Tracking, сигнатура и движение цели в этом числе не моделируются.

Для ракет берутся модифицированные скорость `v`, время полёта `t`, масса `m` и agility `a`. Радиус корабля `r` учитывает появление ракеты из центра корпуса. Верхнее время `T = ceil(t + r/v)`, продолжительность разгона `A = min(T, m*a/1e6)`, путь `R = max(0, v*(T - A/2) - r)`. Для автонаводящихся ракет дополнительно применяется их предел дальности. На верхнем рубеже часть ракет может не долететь из-за серверного округления. Погоня, скорость сближения, дальность захвата цели и помощь других кораблей здесь не моделируются. Рубеж описывает оружие, а не полный сценарий боя.

Перегрев дальности вооружения специально не включается; состояние остальных модулей сохраняется из выбранного фита. В подсказке перечислены оружие, выбранный дальний заряд и его дальность. Ошибки отдельных вариантов сохраняются в подробном дебаге и отмечаются в подсказке.

Механику сверяли с первичными реализациями Pyfa: [дальность ракет](https://github.com/pyfa-org/Pyfa/blob/master/eos/saveddata/module.py) и [применение урона](https://github.com/pyfa-org/Pyfa/blob/master/graphs/data/fitDamageStats/calc/application.py). Код Pyfa в приложение не переносился.

## Скорость

Таблица «ЕГО / ТВОЯ» сравнивает два фита в одинаковых внешних условиях:

- **База**: все AB/MWD выключены; пассивные бонусы и штрафы остальных модулей и ригов сохранены.
- **AB / MWD**: по одному двигателю без перегрева. При двойном разгоне оба двигателя одновременно не включаются.
- Противник: все навыки V, без неизвестных имплантов и бустеров.
- Свой корабль: загруженная карта навыков персонажа, выбранные импланты и бустеры из существующего профиля.

Клока, цино, порталы, bastion/siege/triage, промышленные ядра, doomsday и Clone Vat Bay считаются выключенными для оценки свободного движения. В публичной потере их фактическое состояние неизвестно; автоматически включённая цина не должна обнулять оценку скорости. Список отключённых для этого сценария модулей есть в дебаге. Исходный фит сохраняется.

Для многорежимных эсминцев при сравнении скорости по умолчанию выбирается Propulsion Mode на обеих сторонах. Режим — отдельный dogma-объект из SDE; его модификаторы проходят через тот же расчётчик, включая реальные навыки своего персонажа. Множитель вручную не подставляется. Это допущение описано здесь и в дебаге; в подсказку оно не добавляется.

Если карта собственных навыков не загружена, в колонке «ТВОЯ» стоит прочерк; профиль V не выдаётся за реальные навыки. Внешние сетки, скрамблеры, бонусы флота и перегрев не моделируются.

Более высокая скорость противника выделяется янтарным числом и рамкой карточки; преимущество своего корабля — бирюзовым числом. Сравнение идёт отдельно для каждой строки, после округления до показанных м/с. При равенстве выделения нет. Надпись «ОН БЫСТРЕЕ» и дополнительные символы не выводятся.

Если режимы двигателей различаются, подпись строки содержит его режим / твой режим, например `AB/MWD`. При отсутствии такого типа двигателя на одной стороне для неё берётся доступный двигатель с наибольшей скоростью; без двигателя — база. Разные пары показываются отдельными строками. Подсказка объясняет порядок колонок.

Это сравнение возможностей фитов по прямой, а не измерение текущей скорости в игре. Общая рекомендация боевой дистанции по-прежнему использует существующую приближённую модель боя; показанная скорость не обещает удержание дистанции.

## Нейтрализаторы

Формат: `2× Light · до 5,0 км`. Размеры — Light, Medium, Heavy и Capital. Нейтрализаторы разных размеров или дальностей показаны отдельными строками: дальность одного длинного модуля не присваивается всем остальным. Считаются установленные активные модули выбранного примера, без дронов.

Дальность сохраняет принятую в боевой модели оценку `optimal + 0,25 × falloff`. Это не жёсткий предел: в зоне falloff эффект постепенно снижается. В подсказке доступны optimal и falloff каждой группы.

Подробная диагностика `comparison_ready` содержит `weapon_range` (источники, методы, заряды, число попыток и ошибки), `neutralizers`, `fitted_speed` противника и `own_fitted_speed`. Расчёты остаются локальными и используют существующие кеши, новых HTTP-запросов для этих показателей нет.
