# Руководство пользователя

EVE Combat Assistant оценивает возможный фит выбранного противника и сравнивает его с вашим кораблём. Для первого запуска достаточно установить приложение, импортировать свой фит и настроить две области распознавания. [Скачать последнюю версию](https://github.com/Haeniken/eve-combat-assistant/releases/latest).

## Установка

Поддерживаются Windows 10/11 x64, видеодрайвер с OpenGL 3.3 и компонент Windows OCR для выбранного языка. Используйте оконный режим EVE или окно без рамок.

Установщик создаёт ярлыки и запись в списке приложений Windows. Portable-архив нужно распаковать целиком: рядом с EXE должны оставаться папки `seed` и `licenses`. Запуск — `eve-combat-assistant.exe` или `Запустить.cmd`. Python и Rust не нужны.

`Демонстрация.cmd` показывает пример без сети. У неё отдельные настройки и небольшая выборка Rifter; она не отражает всю статистику zKillboard.

## Настройки

Шестерёнка открывает окно с семью разделами. Кнопка **Сохранить** применяет изменения, **Отмена** закрывает черновик без записи. Ctrl+Enter сохраняет настройки. Если окно невелико, содержимое раздела прокручивается, а кнопки остаются внизу.

| Раздел | Назначение |
| --- | --- |
| Вид | Фон, прозрачность, масштаб, размер окна и пропуск кликов |
| Мой корабль | Собственный EFT, навыки персонажа или выбранный уровень навыков |
| Цель | Ручной выбор корпуса и необязательный ник пилота |
| Экран | Области OCR, проверка распознавания, задержка сброса цели и диагностика |
| Данные | Обновление всей базы, фильтры сборок, поиск фита и рейтинг пилота |
| Фит | Импланты, бустеры и расчёт рекомендаций по расходникам |
| EVE SSO | Вход персонажем, обновление профиля и импорт доступных фитов |

## Ручная цель

В разделе **Цель** выберите источник **Вручную**, корпус и необязательный ник, затем нажмите **Сохранить**. Выбор корпуса из списка или изменение ника автоматически включает ручной режим. Расчёт начинается с локальных сборок; сведения пилота загружаются отдельно. Ручная цель не сбрасывается по таймеру OCR и сохраняется после перезапуска.

Чтобы снова выбирать противника в игре, переключите источник на **Экран** и сохраните настройки. Это та же настройка, что и **Распознавать выбранную цель с экрана** на вкладке **Экран**.

## Свой корабль

В **Мой корабль** вставьте EFT из EVE или Pyfa либо откройте EFT/TXT. В экспорт должны входить установленные модули, заряды, дроны и боеприпасы в трюме. Работают Ctrl+V и **Вставить из буфера**.

Для сравнения скорости нужны реальные навыки: загрузите их через **EVE SSO** или **Импорт навыков JSON**. Без карты навыков в вашей колонке скорости будет прочерк. Выбранный общий уровень навыков продолжает использоваться для остальных расчётов при отсутствии карты.

Боеприпасы подбираются только для оружия. Скрипты Tracking Computer, Remote Sensor Dampener и других вспомогательных модулей не предлагаются как боевой заряд. Пустые орудия проверяются с совместимыми зарядами из трюма. Если экспорт неполный, вставьте полный фит повторно.

Изменения модулей на том же корабле не читаются с экрана. После переоснащения импортируйте EFT заново.

## EVE SSO

Нажмите **Войти через EVE Online**, выберите персонажа в браузере и подтвердите доступ. Client ID уже настроен. Пароль вводится на сайте EVE Online; Client Secret приложению не нужен.

Загружаются навыки, импланты активного клона, текущий корабль, сохранённые фиты и доступные сведения о модулях и трюме. Проверьте результат в настройках и нажмите **Сохранить**. **Обновить персонажа** повторяет загрузку; **Взять фит текущего корабля из ESI** заменяет выбранный EFT доступным снимком.

При закрытых настройках текущий корабль проверяется раз в минуту. При пересадке обновляется профиль и импортируется доступный фит; предыдущий фит другого корабля не используется. На том же конкретном корабле ручной EFT сохраняется.

ESI не отдаёт установленный фит напрямую: приложение восстанавливает его из assets. Эти сведения кешируются сервером и могут приходить с задержкой или не содержать пилотируемый корабль. Сохранённый фит также может отличаться от установленного. В таких случаях используйте ручной EFT. Заряды и скрипты из assets связываются с модулем в том же слоте. Assets могут не содержать загруженные боеприпасы; состояние активных модулей через этот снимок не определяется.

Токены входа хранятся отдельно в `sso.dat`, защищённом Windows DPAPI для текущего пользователя. **Выйти** удаляет локальный вход. Выданный доступ можно отозвать в [списке авторизованных приложений EVE](https://community.eveonline.com/support/third-party-applications/).

## Импланты и бустеры

В **Фит** выберите бустеры из трюма или добавьте предметы по названию. Наличие предмета в трюме не включает его бонус. Активные бустеры и выпавшие побочные эффекты задаются вручную. Имплант должен быть установлен в клоне; загруженные через SSO импланты учитываются в расчёте.

В одном слоте может быть один имплант или бустер. Новая запись заменяет предыдущую. **Рассчитать фит и рекомендации** сравнивает доступный набор PvP-расходников с текущим профилем: DPS, скорость, капу, дальность и другие параметры. Показаны отдельные альтернативы, их эффекты не следует складывать. Расчёт выполняется локально по кнопке.

## Распознавание цели

1. Захватите противника в цель в EVE и выберите его в панели Selected Item.
2. В **Экран** кнопками **Выделить** задайте область текущего выбора справа и область карточек захваченных целей. Первая должна содержать ник и расстояние, вторая — ники и названия корпусов без анимированных колец.
3. Нажмите **Проверить сейчас**. Окна помощника на время захвата скрываются. В **Результате проверки** видны снимки, текст OCR и найденные пилот и корпус либо причина ошибки.
4. В **Координаты и язык** выберите подходящий язык OCR. Названия корпусов ожидаются на английском; в никах поддерживается кириллица.
5. Включите **Распознавать выбранную цель с экрана**, сохраните настройки и закройте их.

По умолчанию чтение приостановлено вне активного окна EVE и пока открыты настройки. После перемещения игровых панелей выделите области заново.

Программа сопоставляет ник из Selected Item с нужной карточкой, затем сверяет корпус со встроенным каталогом. Звание после ника и статус безопасности игнорируются. Звёздочка после корпуса необязательна. Допускаются ограниченные ошибки OCR и однозначные сокращения, но неоднозначные корпуса не выбираются автоматически. При помехах фона выполняются дополнительные чтения с фильтрацией.

После подтверждения цели двумя полными чтениями распознавание кратковременно использует её контекст. При точном нике справа может восстановиться нечитаемая карточка слева; при небольшой ошибке ника нужна точная поддержка карточки с тем же корпусом. Восстановление ограничено тремя интервалами OCR, от 2 до 6 секунд, и не продлевает само себя. Новая цель распознаётся обычным строгим способом. Одиночная небольшая ошибка написания не снимает уже показанную цель; два согласованных полных чтения нового похожего имени заменяют её без пустого кадра.

`10 км` распознаётся как 10000 м, `3 021 м` — как 3021 м. Изменение расстояния обновляет боевую подсказку.

**Хранить исчезнувшую цель** задаёт задержку сброса: по умолчанию 60 секунд, 0 — сразу. Оставшееся время видно в основном окне. При смене цели старые подсказки снимаются сразу.

Без OCR задайте корпус и ник в разделе **Цель**. Для поиска персонального фита и рейтинга нужен ник пилота; для общих сборок достаточно корпуса.

## Быстрый поиск пилота

Лупа рядом с настройками раскрывает поиск пилота без указания корабля. Введите ник целиком и нажмите **Enter** или нажмите лупу в поле. **Ctrl+V** при фокусе на главном окне сам раскрывает поиск, заменяет прежний ник и сразу запускает запрос. Нажимать лупу перед вставкой не требуется. В настройках и окне полного фита Ctrl+V работает как обычная вставка. Перетаскивание не поддерживается.

После загрузки показаны SOLO-рейтинг и групповой маркер. Карточка результата содержит последнюю доступную PvP-потерю: корпус, описание и ссылку на полный EFT, если модули есть в записи. Учитываются и групповые потери, независимо от периода базы и выбранного корпуса. Капсулы всех вариантов пропускаются: выбирается ближайшая более ранняя потеря корабля, даже если перед ней несколько капсул подряд. Это корабль из истории потерь, а не подтверждение текущего корабля пилота. Сведения о потере загружаются после рейтинга. Ответы кешируются на час. Если ESI подтвердил пилота, но zKillboard не предоставил статистику, профиль и поиск потерь доступны. Используется сохранённая оценка, если она есть; иначе рейтинг показан прочерком. Отсутствие статистики повторно проверяется через час. Нажатие на рейтинг открывает профиль этого пилота на zKillboard.

Поиск показывает сведения отдельно. Нажатие на корпус потери или **В помощник** выбирает её пилота, корпус и точный сохранённый фит для расчёта; OCR при этом выключается. Возраст потери и фильтры общей статистики не исключают выбранный вручную фит. Если модулей в записи нет, загружаются общие сборки корпуса. Корпус и ник сохраняются в настройках; точный фит выбранной потери используется в текущем сеансе. Ссылка **EFT** открывает текст фита. Дата потери показана в часовом поясе системы, в формате `дд.мм.гггг чч:мм:сс`.

**Esc** в главном окне очищает текущую цель и поиск пилота, включает OCR и сбрасывает таймер удержания для этой цели. Новое чтение начинается с чистого кеша кадров. Настройка удержания остаётся прежней. В настройках и окне полного фита Esc не выполняет этот сброс. При паузе OCR вне EVE распознавание продолжится после возвращения в игру.

## База сборок

Установка содержит готовую базу всех 423 корпусов каталога за 90 полных дней, 01.08–29.10.2026: 1 381 805 потерь. Записи есть у 369 корпусов. Для остальных каталог и пустая выборка подготовлены заранее; подходящие фиты не выдумываются.

**Данные → Обновить базу всех кораблей** актуализирует весь каталог независимо от текущей цели. Обычное обновление проверяет период от свежих дат к старым и скачивает только новые или дополненные дни. Даже небольшое дополнение требует загрузки дневного архива целиком; неизменившиеся дни пропускаются. Записи, уже имеющиеся во встроенной базе, повторно не копируются. Обновление базы не блокирует поиск фита выбранного пилота. Прогресс показывает проверенные дни, текущую дату, объём загрузки и число новых записей. **Остановить** прерывает работу с сохранением прогресса; следующее нажатие продолжает проверку.

В дополнительных параметрах можно включить **Повторно скачать весь выбранный период**. Это большая загрузка, её лучше выполнять до игры.

Во время выбора цели популярные сборки читаются с диска. Отдельно загружаются сведения пилота: последняя доступная PvP-потеря на том же корпусе может появиться над общими вариантами. Ошибка поиска пилота не скрывает локальные сборки. HTTP-ответы кешируются; для рейтинга срок кеша — один час.

Проценты — доли среди подходящих потерь корпуса после фильтров. Это не распределение фитов всех живых кораблей. Мелкие замены модулей объединяются по оружию, разгону, танку и контролю; для расчёта берётся наиболее частый полный набор модулей внутри варианта. Заряды и трюм не дробят одинаковые наборы модулей.

Флотовые записи отсекаются по числу атакующих, командным и логистическим модулям и другим признакам. Фильтр приблизительный: полный состав флота в killmail не виден. Параметры числа вариантов, доли и покрытия находятся в **Данные**. Вариант можно исключить вручную через контекстное меню; **Сбросить исключения** возвращает его в выборку.

## Чтение основного окна

Клик по рейтингу противника открывает его профиль zKillboard. Клик по своему рейтингу — профиль персонажа, выбранного в EVE SSO.

Нажатие на вариант меняет расчёт; двойной щелчок открывает EFT. Все боевые показатели относятся к выбранной сборке. Список вариантов прокручивается отдельно.

- **Процент возле названия противника.** Доля побед вашего текущего корпуса против этого корпуса за последние 365 полных дней. Сборки и рейтинг пилота на этот процент не влияют. Процент показывается при наличии хотя бы одного исхода. До 50 исходов цвет нейтральный, а подсказка отмечает малую выборку. «—%» означает отсутствие записей. При наведении показаны корпуса, победы, поражения и размер выборки. 50% — зелёный уровень.
- **Дистанция.** Бирюзовый участок линейки — рекомендуемый диапазон; фиолетовая объёмная бусинка — текущее расстояние. Рядом со скрамом, сеткой и жёлтой линией нейтрика подписана их расчётная дальность по выбранному фиту противника. Отдельная бирюзовая линия — ваш поинт или скрам. Янтарная метка — оценочная дальность оружия противника. Бусинка быстро и плавно перемещается после успешного чтения OCR; частота распознавания берётся из настроек. Её свечение мягко пульсирует.
- **Его урон.** Доли типов урона выбранного примера потери, включая оружие, заряды и дронов. Для пушек и ракет дальность определяется с дальними совместимыми зарядами и навыками V; дроны в эту границу не входят. Для дроновой сборки без пушек и ракет показана дальность управления дронами. Знак ≈ отмечает приблизительную границу.
- **Твой заряд и урон.** Заряд из собственного фита или трюма и профиль урона, соответствующий этому выбору. Цвета EM/THERM/KIN/EXP совпадают с резистами.
- **Нейтрики.** Количество × размер и дальность; разные дальности показаны отдельно.
- **Скорость.** База с выключенными AB/MWD и каждый двигатель отдельно, без перегрева. У противника навыки V, у вас — загруженные навыки, импланты и выбранные бустеры. Его преимущество выделено янтарным, ваше — бирюзовым.
- **Резисты.** Итог сверху, база без модулей снизу. Тёмная часть полосы — база, яркая — прибавка модулей. Рамка **ДЫРА** выделяет минимум итогового резиста; при равных итогах учитывается минимум базы.
- **Abyssal.** Если исходный тип неизвестен, используется аналог T2 того же размера или существующий аналог семейства без T2. Появляется предупреждение о неточной оценке; список замен доступен при наведении и в диагностике.

SOLO-рейтинг оценивает результаты и опыт пилота за всё время на zKillboard по шкале 1000–8999. Сегменты кружка показывают один из семи цветовых уровней. Ваш рейтинг расположен внизу возле собственного фита и появляется после входа через EVE SSO; для обоих пилотов используется одна шкала. При недостатке соло-данных показан прочерк. **БЛОБ 10+** означает, что больше половины известных убийств совершены с десятью и более атакующими. **ГРУППА** — минимум 90% убийств несоло, если условие блоба не выполнено. Обе метки требуют минимум 20 убийств и описывают историю, а не текущий состав флота. Зелёная точка внутри плашки означает подтверждённое участие за последние 24 часа, жёлтая — от 24 до 72 часов. Подсказка появляется только при наведении на точку. Если подтверждения нет, точка не отображается. Проверка ограничена одной страницей с часовым кешем. [Формула и ограничения рейтинга](pilot-rating.md).

В **Вид → Звуковые сигналы** отдельно включаются вход в дальность скрама/сетки, нейтрализатора и выход из дальности своего поинта/скрама. По умолчанию сигналы выключены. Они работают по новым распознанным расстояниям: один короткий звук при пересечении границы, с защитой от дрожания OCR и частых повторов. Смена цели или фита, первое чтение и удержание исчезнувшей цели не вызывают сигнал.

Установка содержит компактную годовую статистику противостояний. При обновлении базы новые и изменённые дни добавляются к локальной истории; проценты и цветовые границы пересчитываются по доступному годовому окну. Годовые архивы для первоначальной калибровки готовятся вместе с поставкой. Выделение цели не запускает загрузку общей статистики.

## Диагностика

Системный отчёт `debug/system.json` создаётся автоматически при каждом запуске. В нём указаны версия приложения, сборка Windows, процессор, память, графический драйвер и OpenGL, параметры экранов, языки OCR и версии основных библиотек. Имя пользователя, имя компьютера, серийные номера и переменные окружения в отчёт не включаются.

Подробные журналы и снимки по умолчанию выключены. Для разбора проблемы в **Экран** включите **Подробная диагностика**, сохраните настройки и воспроизведите проблему. Затем нажмите **Открыть папку**. Для ручной проверки флажок действует сразу, без сохранения.

Диагностика хранится в `%LOCALAPPDATA%\EVECombatAssistant\debug`:

| Файлы | Содержимое |
| --- | --- |
| `system.json` | Системный отчёт последнего запуска; создаётся независимо от подробной диагностики |
| `ocr.jsonl` и предыдущие журналы | Исходный текст, координаты слов, повторы OCR, найденная цель и причины отказов |
| `*.png` | Снимки выбранных областей при проверке и распознавании |
| `fits.jsonl` и предыдущие журналы | Выборка фитов, причины фильтрации, расчёты, кеш и трассировка HTTP: статус, задержка, повторы |

Токены, заголовки авторизации и полные HTTP-ответы не записываются. Снимки содержат игровой интерфейс и ники; перед публичным вложением проверьте их содержимое. Для разбора ошибки приложите содержимое `debug`, укажите время сбоя и ожидаемую цель.

Хранятся до 512 PNG общим объёмом 64 МиБ и по четыре журнала OCR/фитов примерно до 20 МиБ каждый. Выключение подробной диагностики прекращает запись журналов и снимков; системный отчёт продолжает обновляться при запуске. Сохранённые файлы можно удалить вручную.

## Хранение и удаление

При установке новой версии поверх предыдущей настройки, вход EVE SSO и пользовательская база сохраняются. Установщик заменяет файлы программы и поставляемый снимок базы. Удалять старую версию перед обновлением не требуется.

Настройки и пользовательская база находятся в `%LOCALAPPDATA%\EVECombatAssistant`, демонстрация — в подпапке `demo`. Стартовая база `seed/seed.sqlite3` рядом с EXE открывается только для чтения. Обновления сохраняются отдельно и учитываются вместе с ней без дубликатов.

Для другой папки используйте `--data-dir "C:\EVEData"`. SQLite следует хранить на локальном диске Windows.

Установленную программу можно удалить через **Параметры Windows → Приложения → Установленные приложения**. Данные сохраняются, если не включить флажок их удаления. Папки, заданные через `--data-dir`, не удаляются автоматически. Служб, задач планировщика и автозапуска приложение не создаёт.

## Ограничения модели

Рекомендации основаны на примерах опубликованных потерь и приближённой модели применения урона. Текущий фит противника неизвестен. Модель не воспроизводит полностью управление орбитой, активный ремонт, капбустеры, перегрев и помощь других кораблей. Оценка дальности оружия не гарантирует безопасную дистанцию.

Если в выбранном примере не определяется исходящий урон, совет по дистанции и заряду для него недоступен. Рассчитанные резисты и другие варианты остаются доступны. Причина записывается в диагностику.
